# 🛡️ PhishGuard AI — Phishing Detection System

> **Real-time ML-powered Cybersecurity Project** · Flask + Scikit-learn + Vanilla JS  
> Built by Bhavani B | Tamil Nadu, India

---

## 📌 Project Overview

PhishGuard AI is a full-stack, real-time phishing URL detection system powered by a **Random Forest** machine learning model. It extracts **16 behavioral URL features** and classifies any URL as **Phishing** or **Legitimate** with a confidence score — all in under 100ms.

---

## ✨ Features

| Category | Details |
|---|---|
| **ML Model** | Random Forest (200 estimators), trained with cross-validation |
| **Feature Extraction** | 16 signals: URL length, subdomains, IP, HTTPS, brand impersonation, TLD, keywords, and more |
| **Real-time API** | Flask REST API (`/api/predict`) — no page reloads |
| **Confidence Score** | Probability meter showing Phishing% vs Legitimate% |
| **Risk Levels** | Critical / High / Medium / Low classification |
| **Scan History** | In-session history of last 50 scans |
| **Model Stats** | Accuracy, F1, ROC-AUC shown live on dashboard |
| **Responsive UI** | Works on mobile and desktop |
| **Loading Animations** | Multi-step loader text, bar animations |
| **Error Handling** | Input validation, network errors, model-not-loaded state |

## ⚡ Quick Start

### Step 1 — Clone / Navigate to project folder
```bash
cd phishing-detector
```

### Step 2 — Create a virtual environment (recommended)
```bash
python -m venv venv

# Activate:
# Linux/Mac:
source venv/bin/activate
# Windows:
venv\Scripts\activate
```

### Step 3 — Install dependencies
```bash
pip install -r requirements.txt
```

### Step 4 — Train the model
```bash
python model.py
```
This will:
- Load `dataset.csv`
- Extract features from all URLs
- Train a Random Forest with 5-fold cross-validation
- Print accuracy, precision, recall, F1, ROC-AUC
- Save `model.pkl` and `model_meta.json`

### Step 5 — Run the Flask app
```bash
python app.py
```

### Step 6 — Open in browser
```
http://127.0.0.1:5000
```

## 📊 API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/` | Dashboard UI |
| POST | `/api/predict` | Predict URL → `{ url }` body |
| GET | `/api/model-info` | Model accuracy + metrics |
| GET | `/api/history?limit=10` | Recent scan history |
| GET | `/api/stats` | Session statistics |
| GET | `/api/health` | Health check |

### Example API call (curl)
```bash
curl -X POST http://127.0.0.1:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{"url": "http://paypal-secure-login.tk/verify"}'
```

## 🤖 ML Features Extracted

1. URL Length
2. Has `@` Symbol
3. Has IP Address
4. Subdomain Count
5. Uses HTTPS
6. Has Suspicious Keywords
7. Suspicious Keyword Count
8. Has Suspicious TLD (`.tk`, `.xyz`, etc.)
9. Brand Impersonation Detection
10. Special Character Count
11. Has Double Slash (after protocol)
12. Path Depth
13. Has Query Parameters
14. Uses URL Shortener
15. Digit Ratio in Domain
16. Domain Name Length
